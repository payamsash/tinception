# Tinception

Multi-site structural MRI study of chronic tinnitus. It looks at three things:
- how hearing loss and tinnitus affect the brain differently
- normative modelling
- how individual patients differ (heterogeneity and subtypes)

The v1 code lives in `legacy/` for reference only. Nothing imports it.

## Layout
```
config/        paths.yaml (local / cluster), sites.yaml (site registry), analysis.yaml (parameters)
tinception/    package: ids, io (ID-keyed merges), phenotypes/ (adapters, audiometry, harmonize), bids, inventory
scripts/       numbered entry points (00_…, 01_…, …)
slurm/         SLURM array templates for the UZH ScienceCluster
containers/    pinned container images (FreeSurfer 8.0.0, MRIQC, CAT12)
tests/         pytest
legacy/        v1 code and docs (read-only)
```

## Environment
```bash
uv sync --all-extras          # creates .venv (Python 3.12, pcntoolkit 1.3)
uv run pytest
```
Choose where scripts run with `TINCEPTION_ENV=local|cluster`. The paths for each are in `config/paths.yaml`.

## Run order (milestones M1–M2)
| step | command | writes |
|---|---|---|
| 00a | `uv run scripts/00a_inventory.py --out cleanup` | `cleanup/cleanup_manifest.tsv`: review it and set `approved=yes` on the rows you accept (read-only step) |
| 00b | `uv run scripts/00b_reorganise.py cleanup/cleanup_manifest.tsv [--execute]` | moves, archives or deletes the approved rows; dry run unless `--execute` |
| 02  | `uv run scripts/02_bids.py` | `rawdata/code/id_map.tsv`, `image_sources.tsv`, `needs_freesurfer.tsv` (plan only) |
| 01  | `uv run scripts/01_phenotypes.py` | `rawdata/participants.tsv` + `participants.json` (the master table), `code/missingness_by_site.tsv` |
| 02  | `uv run scripts/02_bids.py --copy --verify` | unified BIDS in `rawdata/` with an md5 check against the sources |
| 00  | `bash scripts/00_setup_env.sh` (on the cluster) | containers, uv env |
| 00  | `sbatch slurm/00_build_freesurfer.sbatch`, `sbatch slurm/00_install_mcr.sbatch` | exact-match FreeSurfer 8.0.0 Ubuntu20 image + MATLAB Runtime R2019b (for segmentHA_T1.sh / segmentThalamicNuclei.sh) |
| 04  | `sbatch --array=1-N%50 slurm/04_recon_all.sbatch <list.tsv>` | FreeSurfer 8.0.0: new subjects get full recon-all; legacy subjects get only the missing qcache / hippo-amyg / thalamus |
| 03  | `sbatch --array=1-N%60 slurm/03_mriqc.sbatch <list.tsv>` | MRIQC 24.0.2 IQMs in `derivatives/mriqc-24.0.2/` |
| 03  | `uv run scripts/03_qc.py euler …` then `aggregate …` | `code/qc/qc_metrics.tsv`, `qc_exclusions.tsv` (fill `manual_decision` after visual review) |

## Conventions
- Subject ID is `sub-<site><original id>` using letters and digits only. A site prefix is always included because sites reuse IDs.
- Every table is merged on `participant_id` with strict checks. Tables are never aligned by row order.
- `participants.tsv` is generated by `01_phenotypes`. Never edit it by hand. To add a site, add an entry in `config/sites.yaml` and an adapter in `tinception/phenotypes/adapters.py`.
- Sex coding in the legacy sheets is 0 = F, 1 = M. This was checked against eTIV at all 13 legacy sites.
